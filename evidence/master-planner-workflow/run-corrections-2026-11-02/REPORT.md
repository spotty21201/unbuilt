## What was preserved and how the model changed

The former rectangular/single-product restrictions do not govern this path. Existing polygon boundaries, given protected outlines, irregular flexible polygons, multiple explicit products, street-facing groups, measured curves/heads, legacy tools and finances are preserved. This correction reuses those implementations, rather than claiming they were all newly built.

Only new V2 input records opt into `inputCommitments`. It cannot contain allocated groups/held lots; future obligations are visible and its result remains a site/input-stage reservation. A measured layout clears the flag. The shared entrance helper retains its previous behavior; the UI deliberately enters the commitment stage when choosing an input gate. Existing V1 calculation behavior is untouched and existing saved accepted V2 plans are not regenerated on load. Original project and its11 alternatives deserialize exactly unchanged.

The geometry chain remains inputs/locks → roads and real corridors → subtraction/blocks → coherent groups/lots → validation → schedules/comparison. Existing accept/cancel transactions and complete-operation history are retained. Product dimension changes regenerate polygons, failed mix/conflicting held lots block acceptance, and failures keep the accepted scenario intact.
