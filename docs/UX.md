# UNBUILT — UX (Designer stub, M0)

Five stages: Bring site → Confirm understanding → Set intentions → Explore futures → Challenge and decide.
Layout: large spatial canvas; compact commitments panel; up to three alternative cards; small instruction bar; calculations in inspectable drawer.
States: honest no-result (tested scope + blockers), unsupported-assumption, stale-response, model-unavailable with deterministic fallback.
Alt cards show homes, green area, land allowance/gap, blockers; titles from measured deltas; fewer than three when search yields fewer.
Full interaction spec lands with Designer agent before UI build.
